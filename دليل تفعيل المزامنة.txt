====================================================
دليل تفعيل المزامنة السحابية (5 دقائق — مجانًا)
استوديو شروق إبراهيم — الإصدار 3.0
====================================================

الخطوة 1: إنشاء مشروع Firebase (دقيقتين)
-----------------------------------------
1. افتحي الموقع:  https://console.firebase.google.com
2. سجّلي دخول بحساب جوجل (Gmail) بتاعك
3. اضغطي "إنشاء مشروع" (Create project)
   - الاسم: Shorouk Studio
   - Google Analytics: ممكن تقفليها (مش محتاجينها)
   - اضغطي Create

الخطوة 2: إنشاء قاعدة البيانات (دقيقة)
----------------------------------------
1. من القايمة الجانبية: Build ← Realtime Database
2. اضغطي "إنشاء قاعدة بيانات" (Create Database)
3. اختاري الخادم: United States (أو أقرب دولة)
4. اختاري "ابدأ بوضع الاختبار" (Start in test mode)
   ثم Enable

الخطوة 3: تعديل القواعد الأمنية (نص دقيقة)
-------------------------------------------
1. بعد ما قاعدة البيانات تتفتح، روحي تبويب Rules
2. امسحي اللي فيه وحطي ده بالظبط:

{
  "rules": {
    "studios": {
      ".read": true,
      ".write": true
    }
  }
}

3. اضغطي Publish

⚠️ الأمان: البيانات محمية بكود المزامنة اللي هتحدديه
في التطبيق — محدش يقدر يوصل لبياناتك غير اللي معاه
الكود ده. خليه سر ومتشاركيهوش.

الخطوة 4: نسخ إعدادات الاتصال (دقيقة)
--------------------------------------
1. اضغطي على أيقونة الترس ⚙️ بجانب "Project Overview"
   ← Project settings
2. انزلي لتحت لقسم "Your apps"
3. اضغطي أيقونة الويب </>
4. سجّلي اسم التطبيق: Shorouk Studio
   واضغطي Register app
5. هيظهرلك كود فيه firebaseConfig = { ... }
   انسخي الجزء جوه الأقواس بالشكل ده:

{
  "apiKey": "xxxxxxxx",
  "authDomain": "xxxxxxxx.firebaseapp.com",
  "databaseURL": "https://xxxxxxxx-default-rtdb.firebaseio.com",
  "projectId": "xxxxxxxx",
  "storageBucket": "xxxxxxxx.appspot.com",
  "messagingSenderId": "xxxxxxxx",
  "appId": "xxxxxxxx"
}

(لو databaseURL مش موجودة في الكود، هتلاقيها في
تبوع Realtime Database أعلى الصفحة — ضيفيها)

الخطوة 5: التفعيل في التطبيق (نص دقيقة)
----------------------------------------
1. افتحي التطبيق ← تبويب "الإعدادات"
2. في خانة "كود المزامنة": اكتبي كلمة سر خاصة بيكي
   مثال: shorouk-studio-2026
   (نفس الكود ده هتكتبيه على كل جهاز)
3. الصقي كود JSON اللي نسختيه في خانة Firebase
4. اضغطي "تفعيل المزامنة"
5. مؤشر الحالة فوق هيبدأ أخضر: ☁️ متزامن

كرري الخطوة 5 على كل جهاز (موبايل / لابتوب)
بنفس الكود ونفس إعدادات Firebase.

====================================================
ملاحظات مهمة
====================================================
• التطبيق يشتغل أوفلاين عادي — أي حجز تسجّليه من غير
  نت بيتحفظ على الجهاز ويتزامن أول ما النت يرجع
• الداتا القديمة عندك مش هتتمسح — التطبيق بياخد
  أحدث نسخة تلقائيًا (لو فيه تعارض، الأحدث يكسب)
• اعملي "نسخة احتياطية" من وقت للتاني كحماية إضافية
• لو عايزة توقفي المزامنة: زر "إيقاف المزامنة" في
  الإعدادات — البيانات هتفضل محفوظة على الجهاز
